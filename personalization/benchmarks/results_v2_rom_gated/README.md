# ROM-gated V2 offline smoke artifacts

These files are generated by:

```bash
python3 -m personalization.benchmarks.run_rom_gated_v2_smoke
```

They are `OFFLINE_ALGORITHM_DEVELOPMENT_ONLY`, `NOT_HUMAN_READY`, and
`NOT_ROBOT_APPROVED`. The four ROM cases are synthetic software fixtures, not
patients or clinical population evidence. Endpoint values are offline
inverse-dynamics development proxies and must not be interpreted as safety,
comfort, pain, human, clinical, or robot-effectiveness results.

- `ROM_GATED_V2_SMOKE_SUMMARY.json` records Stage 0 ledgers, frozen ROM
  profiles, domain invariant summaries, and overall pass flags.
- `ROM_GATED_V2_SMOKE_RUNS.csv` records the 16 same-ROM K=4 smoke runs.
- `checksums.sha256` covers the JSON and CSV artifacts.

Robot actions: 0. Human actions: 0. PINN training runs: 0.
