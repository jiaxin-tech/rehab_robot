## 先回答当前三个问题

### 是否必须马上采集“机械臂+假腿”的同步轨迹？

分两步：

1. **获取参考几何时，不必须同步假腿数据。** 先用原厂拖动记录机械臂连接后实际的六维位姿，保留小腿自然转动带来的工具朝向变化。这个记录的目的，是确定刚性机构真正能走的空间路径。
2. **做论文中的带腿验证时，需要同步机器人和假腿证据。** 机器人状态/六维受力用于评价机械负荷；假腿ADS数据用于证明假腿确实被牵引、记录关节状态和保护条件。若ADS仍失败，可以先做机器人参考和机器人受力方法调试，但论文必须把“假腿同步验证未完成”写成限制，不能声称已完成带腿实验。

当前仓库还没有一轮新的同步成功记录。2026-11-22联合会话在219帧、约0.478秒后因`input toggle stopped changing`失败；没有完整10秒`CAPTURE_COMPLETE`。因此现在不能直接开始正式带腿负荷比较。

## ROKAE工具/工件问题是不是参考采集的前置条件

不完全是。几何示教只需要一个**稳定且记录清楚的坐标约定**：

- 如果当前使用`tool0`，官方定义是法兰原点，TCP与法兰重合、动力学参数为0且不可修改。可以用它记录法兰参考几何，并在记录中标明“法兰坐标约定”。
- 如果当前已经选用了其他工具，保持选择不变，记录工具名；不要在轨迹采集前反复切换工具或启动自动负载辨识。
- `wobj0`/基坐标可以作为只读记录的参考。工件坐标系是几何参考，不会自动建立假腿动力学模型。

“执行辨识”“运动至”属于会驱动机械臂的命令。此前珞石界面经常返回“发送命令失败”，而且刚性连着假腿；不要用自动负载辨识来获得参考轨迹。工具负载、重力补偿和受力标定是后续负荷评价的前置条件；记录工具坐标本身不依赖完成动力学辨识，但实际拖动仍需满足原厂负载、控制与保护条件。不能用“程序只读”跳过这些条件，也不能把未标定的原始力直接称作校准交互力。

## reference 应该怎样设计

采用三层 reference：

### R0：任务幅度/节奏参考

当前10厘米/10秒五次曲线属于R0。它只有`时间、竖直位移、速度、加速度`，用于表达“想上抬多少、希望多慢”，`ready_for_execution=false`。它没有TCP起点、工具朝向、关节约束和夹具变换，不能送入`run`。

### R1：刚性连接实测几何参考

这是下一条真正要采集的参考：

- 机械臂与小腿刚性连接，髋基座固定；
- 原厂拖动低速完成“起点稳定 → 缓慢上抬/前伸 → 返回起点”；
- 记录机器人实际`XYZ + RPY + 六轴关节角`，不固定工具朝向；
- 录制时长先取30–60秒，不强求10秒完成，也不追求原90秒大幅度；
- 起点和终点尽量闭合，保留2–3秒稳定段；
- 在记录表中标出`settle / lift / reach / return`阶段和现场限位/停止事实。

R1是**实测可达几何**，不是可执行轨迹。现有`record_rehab_trajectory`可做只读机器人记录，`preview_recorded_trajectory`可检查缺口、闭合和朝向变化；不要调用旧的`design_taught_trajectory.py`，它会丢弃录制的朝向变化，旧固定朝向执行链也不适用于刚性连接。

R1的姿态分析应把记录的六维位姿视为一个整体。原始文件可保留Euler角，但插值和重定时前应离线转换/检查连续姿态，不能只平移XYZ再强行把RPY固定成起点。

### R2：审核后可执行的带腿路径

只有在R1完成以下审核后才能形成R2：

- 真实TCP位置和朝向连续；
- 起点/终点闭合，范围远离膝伸直端和其他停止边界；
- 工具/法兰约定、安装刚性和停止方式已记录；
- 机器人控制器支持该段完整六维姿态；
- 速度、加速度、受力和数据新鲜度保护通过；
- 假腿ADS同步采集已经有新鲜、完整的证据。

R2再离线重定时到目标周期。若R1实际竖直位移不是100毫米，不能直接把它拉伸到100毫米；应以实测路径作为主 reference，另把R0的10厘米作为目标幅度，必要时先做更小的试验段。当前加载协议对`rigid_fixture`仍阻止固定朝向自动执行，不能绕过守卫。

### 第二步：独立记录R1完整六维几何

假腿复测成功后，在原厂拖动状态和支撑已确认的前提下，使用机器人只读录制器记录30–60秒慢速上抬—回落。这个步骤不调用“运动至”、不做自动负载辨识，也不要求同时读取ADS；它只获取R1几何。录制成功后先离线预览，不运行旧固定朝向设计器。

### 第三步：再做同步联合观测

当前仓库没有一条已经放行的“机器人全六维位姿+机器人wrench+ADS腿数据”联合轨迹命令。现有`lab_session observe`可以观测机器人和受力，独立假腿诊断可以观测ADS，但两者尚未形成经过验证的刚性带腿同步执行入口。R1和ADS单独通过后，才需要补齐联合采集的时间戳、启动顺序、停止清理和失败保留，再进行正式带腿受力试验。

## 论文最小可行路线

在2027-01-15前，优先保证证据链闭合：

1. 一条R1完整六维刚性带腿参考；
2. 一次新鲜、完整的独立ADS假腿采集；
3. 一轮同一安装条件下的同步机器人状态、wrench和假腿数据；
4. 在同一R1几何上比较一个公共节奏和一个候选节奏，重复并审核任务完成、力/力矩和假腿状态。

如果第2步仍失败，可以先完成机器人几何和受力链调试，但论文主张应收窄为“机器人端负荷方法/空载或台架受力结果”，不能写成完整假腿同步验证。不要继续在R0标量曲线、珞石自动辨识和固定朝向90秒曲线之间反复切换。
