# MyoLeg 仿真研究与论文计划：2026-09-23 至 2026-10-31

目标是在 **2026 年 10 月 31 日前关闭实验，11 月进入集中写作**，面向有影响力的康复/医疗机器人期刊或机器人会议形成可审查的研究工作。研究重点是固定 ROM 下轨迹协调的机械收益、低试验预算的决策质量，以及物理先验何时值得使用。投稿定位由最终证据决定，不预设 Model-Informed BO 必须胜出。

## 2. 研究问题与可证伪假设

1. **轨迹是否值得优化，是否值得个体化？** 在相同 ROM、周期和约束下，候选轨迹相对原参考能否改善 E3；不同主体是否需要不同选择，而非一条共同轨迹即可获得相同收益。改善参考与证明个体化必要性分别检验。
2. **低预算下物理信息是否提高决策质量？** 在包含参考的四次试验内，物理均值加残差 GP 的方案是否优于纯 BO、随机及空间填充，且不会增加不可行推荐和违规试验。
3. **EI 探索是否提供额外价值？** 对比同一物理+残差 GP 的后验均值 Greedy 与 EI，隔离采集函数的贡献；再对比纯物理 Greedy，隔离残差建模的贡献。
4. **结论是否经得起噪声与预算变化？** 比较 1%/3% 采样噪声和 K=2/8；分析先验误差、可优化空间与方法优势的关系，不根据结果追加有利模型或删除困难主体。

如果共同轨迹已接近各主体最优，或 EI 与 Greedy 无稳定差异，应以边界条件和更简单方案为结论。只有证据支持时，才把“个体化必要性”或“探索优势”写入论文贡献。

## 3. 公平实验主协议

以下设置是10月扩展实验的目标协议，正式运行前形成同一份机器可读配置并与代码版本一并冻结。9月23日已完成实验的实际配置以r2的protocol.json为准，Random为5种子、噪声仅native的10种子；不能将后续30种子计划倒写为本轮执行设置。已有development/native结果继续用于开发，不称预注册确认结果。

| 项目 | 主设置与报告要求 |
|---|---|
| 主体 | 原 V1 的 24 development；native nominal 单列，不进入队列均值。沿用原六因素、范围、模型 delta、24/8 划分，不以算法收益扩展模型异质性 |
| 候选族 | `BETA_TIMING` 与 `KEY_POSTURE_TIMING`；保留现有网格、ROM、24 s 周期和原参考。分别报告两族结果；若开发后选择一族，确认阶段使用已冻结选择 |
| 主端点 | E3：四个髋/膝×屈/伸分支 RMS 相对同主体原参考的比值等权均值，参考值为 1。同步报告 E2（四比值最大值）、原始 Nm 分量与峰值 |
| 主约束 | E2≤1.01，各关节峰值≤该主体参考的1.10倍；运动学先筛速度峰值≤1.5倍、加速度峰值≤2倍，并保留 ROM/闭合等完整性检查。E2≤1.00/1.02仅作预定敏感性分析；全部是仿真比较限值，不称临床安全阈值 |
| 预算 | 主 K_total=4，含首次参考；K=2/8 作敏感性。使用同一8步序列的预算前缀，前提是算法不依赖最终预算。不合格/失败试验仍计入预算；不重复候选，不补送免费试验 |
| 无噪主分析 | 确定性方法每主体/候选族运行一次；Random 用固定30个种子。Reference 为一次原参考的锚定对照，明确其试验数，不伪称它使用了四次探索 |
| 噪声稳健性 | 在完整关节力矩采样上加入标准差为对应参考关节 RMS 的1%/3%的零均值独立高斯噪声；由同一带噪信号计算标量和灰箱载荷。所有方法使用0–29共30个配对种子；这是合成采样噪声，不等同于真实传感器误差 |
| 随机性配对 | 噪声键由主体、候选、噪声级别、重复种子组成，不含算法名；相同候选得到相同噪声实现。所有方法共用相同带噪参考；噪声尺度由环境设定，未执行候选时序不向算法公开 |
| GP 配置 | 固定输入归一化、Matérn核、长度尺度、信号尺度、EI参数和破同分规则；Pure/Residual使用一致噪声处理。新实验实现对噪声的近似须与旧E3近零噪声GP区分，正式试验前固定传播规则，并报告参考分母相关性等尚未建模的部分 |
| 信息边界 | 每次只返回已请求候选的观测。运动学筛选可以提前做；未知力矩约束只能执行后揭示。候选全景、真实可行集合、oracle及主体真实参数不得进入选点器 |

七算法的差别只保留在预定模型和选择规则上：

| 算法 | 规则与消融角色 |
|---|---|
| Reference | 固定原参考，提供改善基线 |
| Random | 参考后从未执行的运动学合格候选均匀抽样 |
| 3D Space Filling | 在统一归一化三维坐标上，选择到已执行集合最小距离最大的候选；固定同分规则 |
| Physics Greedy | 每轮用已执行时序更新五参数灰箱，选择最低物理预测值 |
| Residual GP Mean Greedy | 相同灰箱和残差 GP，仅最小化预测均值，隔离残差修正作用 |
| Pure BO EI | 仅获得相同试验的标量端点/不确定度，以普通 GP+EI选点 |
| Model-Informed BO EI | 与 Residual GP Mean Greedy 相同模型，用EI选点，隔离探索作用 |

五参数模型只拟合已执行数据；不得用主体的生成参数作为辨识初值。由 MyoLeg 力矩及 Jacobian 计算的等效平面力应标为“代数等效力”，不能写成束带传感器测量。拟合失败、Jacobian不适定或模拟器完整性失败都须记录并采用冻结的回退规则，不按结果临时重试或删样本。

## 4. 最终推荐、评分与选优

每个预算末，算法从其可见的已执行、观测合格候选中按冻结规则选出最终推荐；参考为预设候选，无可用改进时允许保留参考。只有完成这一选择后，独立评估器才读取该推荐的无噪真值。**不得由评估器在已执行集合中寻找真实最优，再替算法推荐。**“已执行集合的真实最佳”可另列为搜索覆盖次指标。

统一输出以下互补结果，不用单一E3均值掩盖失败：

- 最终推荐真实合格率、各类约束违反数/率；全部已执行试验的违规次数及运行失败数。
- 每主体最终推荐的真实E3、相对参考改善、E2及峰值；完成但真实不可行的主比较损失记为 `max(1, E3)`，未完成/算法失败/无推荐记为1并另报失败，防止以不可行低E3获得优势。这是比较用惩罚，不代表真实系统执行了参考回退。本轮 `improvement_pct=100×(1−selection_loss)` 为惩罚后改善，原始真实E3也保留；有噪时须区分观测超限次数与最终推荐的真实合格率。
- 各预算学习曲线、运行诊断；本轮 `elapsed_s` 包含最长预算的模拟、缓存命中先后及拟合，不用于算法速度排名。如需比较算法效率，另行隔离学习/选择耗时并冻结测量方法。开发阶段有独立全景时可报相对可行oracle的regret；本轮无完整oracle，不要求该列也不声称找到全局最优。
- 优化空间与主体差异：参考、共同轨迹、主体最优的差距和跨主体迁移。开发阶段共同轨迹的选取应避免同主体自评偏差；确认阶段共同轨迹必须从development冻结，不在held-out重选。

统计单位是**主体**。先在每主体内汇总30个配对种子，再计算主体配对差及95%区间；可用主体层 bootstrap，或保持主体结构的分层bootstrap。不能把24×30当作720个独立主体。8个held-out须展示逐主体结果，区间只反映该合成设计下的有限样本不确定度，不外推患者总体。

主比较预定为 MI-EI 对 Residual GP Mean Greedy、MI-EI 对 Pure EI，在两个候选族分别分析；若报告显著性检验，对这四项比较作Holm校正。其余对比与噪声/预算/约束结果作为开发或稳健性分析完整报告。

开发选优顺序：先比较真实可行率和违规数，再比较K=4的主损失/E3及区间，最后考虑计算量与实现复杂度。不得挑最有利种子或仅报告获胜子群；当优势不明确时，保留“并列/无明确胜者”，工程默认可选更简单方法。候选族、算法、超参数、失败处理及分析脚本选定后统一冻结，held-out仅做一次事先规定的确认，不参与再选优。

公共轨迹基线用于回答“是否需要给每个主体分别搜索”，不能仅用原始参考代替。先固定一个仅由运动学定义的公共候选集合，再在development内部按主体留一或预定分折选择共同参数，在未参与该次选择的主体上评分；共同轨迹自身超限也保留为失败，不由测试主体真值替换候选。可先使用预定有限集合，必须标明它是“训练得到的公共基线”，不是穷举共同最优。确认阶段用全development确定并冻结一条共同轨迹；held-out仅评估它。公共基线的离线训练成本与新主体试验数分别报告，避免把跨主体预训练信息当作免费信息或给个体化方法偷看测试主体。

## 5. Development 与 sealed 流程

保留原32个主体身份与24/8分割。依照 [HELD_OUT_TRUTH_ACCESS_POLICY_V1](../../external_simulation_audits/myoleg_v2_personalization_necessity_audit_v1/HELD_OUT_TRUTH_ACCESS_POLICY_V1.json)，held-out在“final algorithm freeze and a separately authorized confirmatory evaluation”前保持封存；本轮开发不读其NPZ、候选代价、oracle、排名或结果统计。

实际流程为：native接口验证 → 冻结开发协议 → 24 development完整比较 → 固定候选族/算法/分析 → 生成可审阅的确认方案 → 按原政策另行授权 → 8 held-out确认 → 冻结表图。不能因10月底目标而跳过信息隔离。如果确认阶段尚未获授权或未完成，论文仅陈述development结果并如实标注限制。

原V1主要改变质量惯量和被动力幅度，不保证出现足够的主体×轨迹交互；重复使用development可帮助方法设计，但不会自动产生新的确认性证据。若需改变肌肉路径、操作长度或其他结构因素，应遵守 [队列版本及划分计划](../../external_simulation_audits/myoleg_musculoskeletal_heterogeneity_expansion_design_audit_v1/COHORT_VERSIONING_AND_SPLIT_PLAN.md)，建立新版本、独立依据和新划分，不为制造个体差异在本轮临时扩域。

## 7. 论文贡献门槛与 go/no-go

“代码跑通”“方法均值排第一”“不同主体选出不同候选”分别是工程结果、样本内排序和选择差异；单独均不足以证明有实际个体化收益或新的算法贡献。主张必须对应下表的证据。No-go意味着撤回或降低该论点，不删除结果，也不以扩大扰动、改端点或窥看held-out挽救结论。

9月23日当前判断：完整开发实验和软件回归已提供继续研究的工程基础；“相对参考的机械改善”有开发数据支持；“逐主体搜索必要性”“残差修正或EI探索带来额外无噪收益”暂不获支持。后续公共轨迹与噪声实验用于检验这些边界，不以获得预定正结论为完成标准。

| 决策门槛与时间 | Go：可以保留的论点 | No-go：应如何调整论文 |
|---|---|---|
| 正确性，09-27 | 参考恢复、同预算、同观测、候选身份与第三维一致；推荐由算法选择；失败有完整计数；全24主体和规定种子覆盖可核对 | 未通过则先修实现，只重跑受影响结果；不基于错误评分或缺失主体选优 |
| 优化意义与个体化，10-04 | 相对原参考有超出数值误差的真实合格改善；相对主体外选择的公共轨迹仍有额外收益，且不是靠增加违规换来的 | 只胜过原参考则论点限于轨迹设计/共同优化；公共轨迹已足够时不宣称必须逐主体搜索 |
| 算法贡献，10-11 | 主K=4下对强基线有可解释的效应和主体配对证据；噪声/约束变化下方向稳定，机制消融能解释收益来源 | MI-EI与残差均值Greedy相当则不主张EI探索创新；只有物理先验有效时，聚焦先验收益与适用条件，工程默认可选简单方法 |
| 真实推荐可靠性，10-11 | 有噪时最终推荐仍具可接受的真实合格率，失败与违规代价明确；优势不依赖真值重选或事后可行筛选 | 推荐常不合格或胜负靠惩罚规则改变时，按失效机制报告，不能仅用低原始E3宣传优越性 |
| 独立确认，10-25 | 冻结前形成明确主张，保留集按原方案支持其方向；逐主体差异和不确定性完整呈现 | 不一致则报告未确认；只有8个合成主体，不能将不显著解释为等效，也不能反复调参再测同一保留集 |
| 投稿准备，10-31 | 至少一项清晰、经强基线/消融/独立评价支持的方法或机制贡献，完整复现材料和诚实边界 | 若只剩实现集成或开发排名，先完成技术报告/预稿与缺口清单；不把较弱证据包装成知名期刊必然可接收的工作 |

最小有意义效应须与“统计差异”分开。正式稳健性分析前，根据参考重复性、数值复现误差和噪声传播确定并记录一个E3工程解释尺度 `delta_practical`，不能根据哪种算法会赢来选阈值，也不能把它称为临床最小重要差异。若该尺度没有充分依据，则只报告连续效应、区间与违规代价，不宣称具有实际意义的优越性。候选ID不同但E3差异低于该尺度，也不算决策相关的个体差异。

可以形成的贡献有两种：一是证据支持的低预算物理先验决策方法，并通过残差/探索消融说明新增价值；二是有独立验证的适用边界或机制发现，解释固定ROM、机械端点与主体参数如何限制个体化。第二种仍需相应的新洞见和验证强度，单纯“某算法未胜出”不自动构成高水平论文贡献。

投稿方向按最终证据选择，不给未经核实的截稿日期或录用承诺：

- **IEEE TNSRE**：康复任务与机械端点应有充分的康复意义和验证依据；若只有合成仿真，需坦诚其与真实测量/患者功能的距离。进入该方向通常需要更强的康复相关验证，不能把仿真E3解释为舒适度、疗效或功能恢复。
- **IEEE T-MRB**：适合强调医疗/康复机器人系统方法、可解释个体化与严格验证；须体现超出离线调参的系统贡献，并完整说明尚未贯通的真机环节。
- **IEEE RA-L**：适合明确的新机器人方法和紧凑、有说服力的实验。仅组合已有灰箱、GP与EI且无稳定额外收益时，不应勉强包装为新算法；应以可证实的机制、决策方法或系统贡献为核心。
- **机器人会议方向**：若形成明确机器人决策/控制方法贡献，可在写作阶段评估ICRA、IROS或其他相关会议的适配性；会议投稿方式和当届日程以官方信息为准。本计划的10月底实验截止是内部目标，不是未经核实的会议截稿日。

最终投稿前再核对各刊当时的官方范围、作者指南和篇幅。知名期刊/会议是目标，不是本计划可以保证的结果。当前研究不支持临床有效性、安全性、患者代表性或实际机器人在线个体化结论；这些需要各自独立的实验与证据。
