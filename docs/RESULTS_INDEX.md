## 证据使用规则

- `OBSERVATION_COMPLETE`只证明观测流程结束；同时看有效样本、时间缺口、清理结果和`motion_commanded`。
- `EMPTY_LOAD_COMPLETE`只证明空载会话完成；不能外推为带腿安全或负荷改善。
- `FAILED`记录不能删除或重命名为成功；失败原因和原始文件是实验边界的一部分。
- `summary.json`中的`hardware_accessed=false`表示离线生成；离线图和CSV不能作为真机运动记录。
- 论文正式结果只能使用冻结配置、完整原始数据、实际任务审核和同一机械条件下的重复试验。
