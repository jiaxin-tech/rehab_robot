# 当前论文与实验工作流

更新日期2026年11月14日。实验室实验硬截止为2027年1月15日，每周两次、每次三至四小时，由一人完成。当前统一分支为`paper-personalized-load`，正式代码继承`cleanup/unified-dummy-leg-mainline`的机器人位姿与受力方法。来源见[整合记录](BRANCH_INTEGRATION_2026-11-14.md)。

实际后续操作和数据回传统一按[实验操作总手册](NEXT_LAB_OPERATIONS.md)逐步执行；现场记录可复制[记录模板](templates/LAB_RECORD_TEMPLATE.md)。

## 本篇只研究什么

工作题目为“面向舒适度相关机械负荷降低的单臂牵引轨迹个性化方法与假腿验证”。在相同机器人空间任务和预先冻结的总周期下，利用少量该机械条件的实测受力选择节奏，检验其是否比合理公共节奏负荷更低。题目是待验证研究方向，不代表创新和效果已经成立。

这里个性化是受控机械条件适配：不同配重、真实阻力元件或安装条件必须可重复、可记录；它们不等于不同患者。舒适度是设计动机，直接测量的是机械臂报告的末端力/力矩负荷；本篇不做人体主观评价，不推导患者更舒服、安全或康复更有效。

正式训练只使用机器人实测位姿、六维受力和时间记录，不需要患者髋中心、有效腿长、连接偏移或真实关节姿态。它不因此保证未知姿态下的临床适用性。假腿角度/力矩可用于台架保护和独立作用验证，不输入正式学习器。机器人完成TCP任务与假腿确实被有效牵引应分别检查。

## 唯一正式代码路线

`scripts/lab_session.py`编排统一配置、独立TCP候选、现场执行、数据审核、训练、重复与归档。学习发生在一轮完整执行之后；执行器仍是实时笛卡尔位置控制，当前没有同轮导纳、实时空间形变、PINN或MPC。

| 职责 | 当前入口 | 证据与限制 |
|---|---|---|
| 配置与现场编排 | `config/experiment.json`、`scripts/lab_session.py` | 每轮新目录，prepare后审核预览，显式run |
| 独立TCP任务 | `control/independent_tcp_trajectory.py` | 起点、空间端点、保持、节奏与实际重定时受限；不读关节参考CSV |
| 机器人采集与执行 | `collection/`、`control/`、`hardware/` | 原始状态、六维受力、dispatch与停止清理记录 |
| 实际任务审核 | `measurement_validation/robot_execution.py` | 检查实际TCP跟随、朝向、时序、缺口和完整周期 |
| 直接负荷与候选决策 | `scripts/tcp_force_training.py` | `load_score`、峰值分数、已有GP/EI工具；方法收益待实测 |
| 可选假腿验证 | `collection/twincat_leg.py`、`measurement_validation/passive_response.py` | 装置验证与保护，不能混入正式训练观测 |
| 原六参数 | `experiment_algorithm/`、`scripts/original_training_adapter.py` | 保留离线对照与GP/决策工具；不恢复为默认部署主线 |

现场命令以[TCP受力实验指南](TCP_FORCE_EXPERIMENT.md)为基础。该指南中的原164/184/184秒候选属于先导；本文件规定的正式同周期比较使用另行审核的论文配置副本。旧几何适配或旧工作区的`lab_next_visit.ps1`、直接关节力矩训练器、24秒参考和历史大套件不是这个分支的正式入口。

## 先导配置与正式模板分开

实际`config/experiment.json`保留最新现场设置，三条先导候选为80/80、100/80、80/100秒，上抬/返回外各保持2秒，总周期164/184/184秒。它适合检查采集、任务执行和节奏敏感性，不能用于“相同总时长”效果主张。

新增`config/paper_personalized_load.template.json`从实际配置复制，仅提出同空间端点、80/80、70/90、90/70秒候选，总周期均164秒。`force_training.fixed_cycle_duration_s=164`约束的是保守限速之后的完整计划周期，包含保持阶段。重定时使周期变化时拒绝这一批可比性；若现场确实需要更慢，应在观察正式效果前统一重定任务并重新冻结，保留原失败记录，不修改限速来迁就模板。

模板不是可运行批准。`study_identity.setup_id`和`mechanical_condition_id`为null，`strict=true`；应按实际安装与机械条件填写并保存定义，不能用虚构编号声称已验证。补偿未核实、无接触偏置未测，继续false/null。`training.enabled`虽保留false，但并非TCP受力训练总开关：完整带载run会自动训练，实际前提由受力标定、身份和任务审核约束。模板没有改变现场空间、限速、限力或假腿ROM。

当前0.9m绝对Z目标与-0.2m水平位移只是沿用配置。需针对真实起点、安装、空间、连接和装置状态审核，不是患者处方。先导或模板不可执行时，先修现场任务定义，不能认为文档中的数字保证适合这台装置。

## 机械端点与舒适度边界

直接方法以有依据的无接触偏置和已核实工具/外力补偿处理六维受力；不能在假腿已受载时清零以消除真实牵引负荷。固定力坐标、参考点、工具和安装，保留原始总负荷。

分别在上抬与返回计算力模长和力矩模长的时间RMS，两分支等权平均，工程目标为`load_score=0.5×(F_rms/F_limit+T_rms/T_limit)`。全周期峰值分数用于约束，保持阶段也纳入峰值。原始力/力矩RMS、峰值、完整曲线、实际任务误差和实际周期必须分别报告，不只呈现复合分数。评分权重与分母在正式比较前冻结，不能通过调整限值改变目标权重来制造改善。

这个目标不是原E3/E2、关节力矩、绑带纯张力、局部皮肤压力或经过验证的舒适度量表。传感器原始有效时序用于负荷评价，不能先降采样到少量命令点漏掉短峰。无效/缺失记录不算零力，峰值分数和GP可行性分数也不是临床安全概率。

## 三个需要被实验检验的假设

第一，相同条件下候选间负荷差异能大于独立完整执行的重复误差和跨轮漂移。若差异不可分辨，先解决测量或任务敏感性，停止优化器比较。

第二，利用本条件自己的少量观测，能在独立复测中优于开发条件中预先冻结的公共节奏。某条节奏对所有条件都更好，只支持通用节奏设计；相对原参考更低也不自动证明个性化价值。

第三，GP/EI在相同在线尝试成本下能否比简单选择更有用。三候选是小目录，全部测量即可枚举，不能把使用GP当创新。强简单对照应包括固定公共候选和相同成本的预定候选顺序/测量后选优；若其效果相同，就保留简单方法或准确报告无额外价值。

公共候选只能由开发条件选择，评价条件不能用完整响应替公共方案选优。每个最终推荐先冻结，再执行独立评价；不把搜索中最小一次带噪观测当最终收益。报告失败、参考、重复、搜索和评价的全部尝试，以及公共离线训练成本。成功parent链长度不是完整实验成本。

适配序列与独立评价序列分开：严格研究身份防止跨机械条件混学，失败仍计一次尝试，STOP后不继续自适应搜索；评价重复显式标注，留在尝试账本但不反哺已经冻结的GP推荐。记录完整试验作为重复单位；机械配置/重新装夹不是患者，传感器行数不是样本量。

## 现场最小顺序

先核对机器人受力方向、无接触偏置/补偿、原始采集质量、完整空载任务、装置安装和停止恢复，再争取一条可信完整假腿参考。今天尚无完整假腿回合时，不把九回合性能比较设为必须完成的目标。

条件具备后，在同一机械条件下用参考R、候选A、候选B各执行三次，可预定RAB、BRA、ABR三个平衡小块。此九回合用于重复性和节奏敏感性先导，允许独立实验安排；不能事后把人工顺序称为算法提出的动作。先导应独立归档，不自动进入正式适配链。

164秒任务的九回合仅运动就约24.6分钟，54回合约147.6分钟；另有复位、稳定、预览、写盘检查、重新安装和异常处理。一人每次三至四小时，应在首个完整回合后按实际周转时间确定后续规模，不承诺一次完成54回合。先导数量不是统计功效保证，正式重复数与精度要求在先导后、确认前决定。

机械条件必须确实可调且可重复，如实测配重、真实阻力元件或安装定义；ADS只读接口不证明假腿可以设置K/B。不同机械条件另起研究历史，同一条件内固定安装。假腿验证测量不够准确时，不反过来把名义轨迹当实际肢体运动。

## 到2027年1月15日的收敛排期

按约十八次现场机会安排，远程代码与数据处理尽量提前完成，不假设个人还有无限额外工时。每次只保留一个主要现场交付。

| 周期 | 现场次数 | 应完成的交付 | 决策 |
|---|---:|---|---|
| 11月14–20日 | 1–2 | 真实配置/安装/机械条件能力；受力坐标、偏置与采集诊断；完整空载证据 | 不具备带载条件就保留原始诊断，不填虚假标定 |
| 11月21–27日 | 3–4 | 一条完整假腿参考及独立重复，测量总周转时间 | 11月27日还未完整执行，暂停扩算法并重估剩余次数 |
| 11月28–12月4日 | 5–6 | 三候选敏感性先导；条件允许时检查少量真实机械条件差异 | 区分候选差异、重复漂移与条件交互，不预定个性化成功 |
| 12月5–11日 | 7–8 | 冻结正式空间任务/周期、端点、条件、公共基线、预算和评价协议 | 12月11日后不新增算法或候选族 |
| 12月12–25日 | 9–12 | 正式适配、公共/简单对照与独立推荐评价；保持预定平衡顺序 | 所有尝试和失败入账，不按中途效果改主端点 |
| 12月26日–1月1日 | 13–14 | 跨日或重新装夹的独立复测；完成预声明主要检查 | 力争主实验元旦前完成，预留两周返工 |
| 1月2–8日 | 15–16 | 补预定缺失、失败记录或必要重复；核对结果来源 | 继续维持12月11日冻结，停止扩范围 |
| 1月9–15日 | 17–18 | 返工缓冲、原始数据与配置最终核对 | 1月15日关闭全部实验室工作 |

12月4日前若候选差异不超过重复误差，先修测量，不堆优化器。若公共节奏对各条件均同样好，应及时向导师说明个性化收益未成立；可以在开发阶段基于具体物理原因重定任务并重新冻结，不能看结果后改权重、调大模拟阻力或降低门槛制造成功。

若最终只支持通用节奏，论文如实收敛；阴性边界结论不自动满足导师的个性化创新要求，应十二月初就沟通。若GP/EI无额外收益，降为消融，不继续为排名扩新版本。当前不保证任何期刊接收，也不将期限作为保留已知错误的理由。
