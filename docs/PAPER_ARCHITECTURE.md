# 论文架构：机械臂受力驱动 TCP 候选决策

2026-11-12。依据用户最终确定的实际康复信息条件和当前代码整理，没有论文原稿或新物理结果。正式主方法仅使用机械臂实测位姿与六维受力，不要求精确患者姿态、髋中心、连接几何或腿长。原六参数方法保留为有条件的离线对照。

## 1. 研究问题与主线

建议工作题目：**面向未知患者姿态的机械臂受力反馈 TCP 牵引轨迹候选决策方法**。

研究问题是：在给定机器人牵引任务和物理限制下，根据已完成轮次的机器人运动与受力，选择下一条负担较小的 TCP 候选。这里不承诺从未知患者几何中唯一辨识生理刚度、阻尼或关节力矩，也不凭力更小直接判定临床效果。

~~~mermaid
flowchart TD
    T[机器人任务与有限 TCP 候选] --> P[独立规划和冻结预览]
    P --> X[ROKAE 实时笛卡尔位置执行]
    X --> O[机器人实测 TCP 与六维受力]
    O --> A[实际任务/数据完整性审核]
    A --> C[直接受力负担与峰值]
    C --> G[已有 Matérn GP 工具]
    G --> D[约束可行性分数与期望改进]
    D -->|下一候选| P
    D -->|STOP| S[停止并归档]
    X --> V[可选假腿验证与台架保护]
~~~

学习发生在轮间。机器人执行仍为 SDK 的实时笛卡尔位置控制，已有力/力矩限负责停止保护；本实现没有同一轮内的导纳控制或实时轨迹修正。

## 3. TCP 候选与任务

现有独立规划器使用七次时间函数连接起点与目标点，保持后原路返回，姿态固定。SDK 在已准入规划端点间做 1 ms 平移插值；名义回调周期不等于已证明硬实时。

特征为水平位移、实际上抬时间、实际返回时间。绝对 Z 峰值、保持时间及采样设置为同一任务的公共条件，水平位移、分支时间和总周期均有界，并要求最小垂直行程。若保守限速触发延时，训练采用延时后的真实特征；不能使用名义时间冒充实际运动。

当前默认三条候选仅比较相同空间端点下的节奏：80/80、100/80、80/100 s，上抬和返回之外各保持 2 s。Z=0.9 m、水平位移=-0.2 m 是沿用的实验任务配置，不是针对患者已验证的处方。空间候选优化接口允许在明确任务区间中增加位移候选，目前默认空间区间固定。

低受力不能替代任务完成。robot_execution.py 审核冻结计划、实际发送时刻、实测 TCP 跟随、朝向、全周期受力、数据缺口和清理记录。没有完成规定运动时拒绝训练。机器人任务完成仍不能证明患者关节 ROM、有效牵引或康复效果。

## 4. 直接受力指标

机器人记录经有依据的无接触偏置处理；表达坐标和受力参考点需跨轮保持一致，工具/负载外力补偿需核实。分别计算上抬与返回的时间 RMS，再对两分支等权平均得到 F_rms 和 T_rms。

$$L=\tfrac12(F_{rms}/F_{limit}+T_{rms}/T_{limit}).$$

两项预测约束为全周期峰值分数 $P_F=F_{peak}/F_{limit}\le1$、$P_T=T_{peak}/T_{limit}\le1$。保持阶段纳入全周期峰值，不用延长保持时间稀释移动分支负担。失效样本不能当作零力，缺口和无效记录被拒绝。

这是新正式方法明确采用的工程目标，不是原 E3/E2 或生理关节力矩，也不能把末端力模长称为绑带纯张力。真实受力阈值和工程权重不等于临床接受标准。

## 5. GP 和候选选择

直接复用现有 Matérn-5/2 GP。特征尺度、长度尺度、噪声和信号幅值下限在 force_training 声明；以首轮观测作为公共常数基线，分别预测 L、P_F、P_T，没有六参数物理先验或患者参数输入。

复用原 constraint_probability 计算模型可行性分数，筛出满足配置分数门限的未试候选，再以 expected_improvement 乘以可行性分数选择下一候选。总预算、候选耗尽、无预测可行候选和乐观改善不足均可触发 STOP。该决策属于经用户确认的新观测/目标方法，不能声称原六参数主方法未变。

重复试验保留原候选 ID，每个完整轮次形成一条观测并更新 GP。噪声下限是工程假设，跨轮患者姿态变化、时间漂移及重复依赖尚未建模；不能从多个采样点或重复记录直接宣称独立重复次数或已校准安全概率。

下一轮预测在运动前写入 pretrial_prediction.json，结束后比较实际结果。训练与推荐核对原始证据及源码哈希，六参数旧训练结果不能冒充当前方法输出。默认台架可保留假腿测量，但训练输入不含它。

## 6. 原六参数离线对照

原 experiment_algorithm 的六个核心文件保持不变：六参数有效力学辨识、物理端点预测、残差 GP 和原 Greedy/约束逻辑。其质量尺度、髋膝刚度/阻尼和耦合刚度仍具有原定义，不重命名为末端参数。

该方法需要可用的关节运动和广义力矩观测。已有 IK/JᵀF 适配依赖已知几何和平面点力假设，因此仅可在信息满足的模拟/离线条件下对照，不能要求实际患者精确姿态或填入猜测值后部署。旧五参数估计器不进入正式主线。

若用六参数方法作比较，必须明确其额外可用信息，不能把带真值/额外传感器的对照宣称与机器人单独观测的信息条件完全相同。

## 7. 现有证据与实验安排

现存 rt_link_004/status.json 保存 1 mm 诊断成功报告、正向约 1.006 mm、返回与清理标志；该目录缺原始状态 CSV，证据能力以归档为限。empty_load_118 属于旧记录，不能代表新的受力学习，也不能否定用户未同步的新空载实验。

当前软件合成回归覆盖：无假腿/患者配置的流程、实际任务审核、直接受力指标、完整训练/下一候选/重复、无效力数据拒绝、证据变更拦截和原六参数回归。没有新的多轮真机受力优化记录，不能写优化收益、显著性、临床安全或疗效。

后续物理实验应依次核对机器人受力/工具与时序 → 独立 TCP 空载反馈 → 台架同任务不同节奏 → 原样重复与跨轮漂移评估 → 模型预测误差与任务效果。试验顺序和初始状态变化需记录；低受力改善可能受姿态变化影响，不能自动当作轨迹的因果效果。
