# 阶段 4.5D：人体几何与运动学观测误差审计

本审计只讨论二维虚拟下肢中的静态几何标定误差、运动学观测误差及其对
五参数辨识和未见轨迹预测的影响。它不是患者测量、临床结论、机器人控制器
或安全阈值。

人体模型继续严格使用：

```text
theta_shank = q_hip - q_knee
```

髋屈曲总工作空间上限仍为 120°，没有引入 `q_hip + q_knee` 机械臂模型。

## 1. 为什么准确动力学仍可能被错误运动学破坏

动力学方程即使完全正确，也需要在正确的关节状态和几何映射上计算。真实
机器人通常观测到束缚带牵引点的 TCP 位置和二维力，而不是人体真实的
`q/dq/ddq`。如果髋中心、`L1`、`L2` 或角度测量有误，逆运动学得到的关节
角会偏差，数值微分得到的速度和加速度也会继续偏差；同时错误的 Jacobian
会把同一个 `Fx/Fz` 重建成错误的关节力矩。于是辨识器面对的是彼此都已被
运动学误差改变的输入和目标，不能仅凭动力学公式正确保证参数可靠。

虚拟数据生成侧可以使用 `true_geometry` 生成真实牵引点和事后评价真值；
观测与辨识侧只能接收测量牵引点、测量力和 `assumed_geometry`。真值关节
状态、真实 Jacobian、理论真实力矩和真实几何不得进入参数拟合。

## 2. `L1` 和 `L2` 误差分别影响什么

`L1` 是髋到膝的长度。它参与膝点位置、牵引点位置和髋膝两列 Jacobian，
所以偏差会同时改变髋角、膝角、膝点位置以及髋关节力矩映射。由于第一连杆
影响后续整条链，`L1` 误差通常不是只落在一个关节上的局部误差。

`L2` 是膝到束缚带等效牵引点的距离，不是小腿质心距离。它主要改变从膝到
作用点的几何闭环、反解得到的膝屈曲角，以及牵引力对关节的力臂。即使有
独立角度传感器消除了反解角度误差，错误的 `L2` 仍会使
`J_assumed.T @ F` 的力矩映射发生偏差。正负方向都必须测试，因为长度高估
和低估不保证产生对称结果，且某一方向可能更早使 IK 超出定义域。

## 3. 髋中心偏移为什么会影响整条轨迹

TCP 反解前必须先减去假设髋中心。一个固定的髋中心 x 或 z 偏移会使每个
采样点都在错误原点下求解，而不是只给角度增加一个固定常数。极坐标方向和
髋到牵引点距离都会随姿态以不同方式改变，所以误差会沿整条轨迹变化；接近
工作空间边界时，还可能造成 IK 定义域失效、关节跳变或适用域误分类。

## 4. 角度噪声经过两次微分后为什么放大

差分近似中，速度会把相邻角度误差除以采样间隔，二次微分又会再除一次。
采样间隔越小，高频噪声在 `dq` 和尤其 `ddq` 中的数值放大越明显。直接对
带噪角度逐点简单差分，可能使阻尼项 `B*dq` 和惯性项 `M*ddq` 被噪声主导。

因此本阶段区分四类导数方法：

- `central_difference_offline` 和 `savitzky_golay_offline` 必须明确标记
  `uses_future_samples=true`，只适合离线分析；
- `causal_backward_difference` 和 `causal_filter_and_difference` 只能读取
  当前及历史角度，但会有更大的噪声或滤波延迟；
- 分段边界和无效角度附近不得跨长缺口微分，导数质量由
  `derivative_valid`、`derivative_reason` 和 `filter_delay_s` 保留。

滤波和微分窗口应预先固定，或只用 train/validation 选择；test 不得参与。

## 5. `q0` 误差为什么会偏置 K

当前线性刚度力矩为：

```text
tau_stiffness = K * (q - q0)
```

`q0` 虽不是运动学连杆参数，却决定弹性力矩的零点。假设 `q0` 偏移 3° 或
5° 后，即使角度 `q` 完全准确，模型中的变形量仍会系统性偏大或偏小。
五参数估计器不能调整 `q0`，便可能通过改变 K、质量或其他项减小训练残差，
从而偏置刚度估计。把 `q0` 临时加入候选参数只用于 K–`q0` 灵敏度和相关性
审计；主估计器仍严格保持
`[mass_scale, K_hip, K_knee, B_hip, B_knee]` 五个参数。

## 6. 为什么等效参数可能吸收部分几何误差

有界最小二乘会在训练轨迹上寻找能最小化残差的参数组合。当角度、导数或
Jacobian 有小幅系统误差时，质量缩放、K 和 B 可以改变预测力矩的幅值与
相位，因而在有限运动范围内补偿一部分观测链偏差。这些数值是“错误几何和
指定训练数据下的等效参数”，不再等同于虚拟受试者的生成参数。

## 7. 为什么这种吸收不等于模型正确

训练残差变小只说明参数在该训练轨迹上提供了局部补偿。同一组参数可能在
不同角度组合、速度、边界姿态或训练域外轨迹上失效，也可能掩盖实际需要
重新标定的髋中心或作用点。必须同时报告 validation、interpolation、
boundary 和 outside-domain 预测、参数偏差、力矩观测误差及端点力误差，
不能用训练拟合好来宣称几何正确或患者参数已恢复。

## 8. 独立相机或 IMU 能够解决什么

`independent_joint_measurement` 模拟侧视相机或两个 IMU 直接测量髋膝角，
可绕过“TCP 位置 + 假设髋中心 + 假设腿长”的逆运动学链。它能显著减小由
髋中心、`L1/L2` 偏差造成的角度重建误差，并可与
`tcp_inverse_kinematics` 交叉检查关节连续性和标定漂移。

三种观测模式的解释边界必须分开：

- `oracle_true_joint_state` 使用真实 `q/dq/ddq`，只表示理论上界；
- `tcp_inverse_kinematics` 是只靠测量 TCP 和假设几何的实际候选链路；
- `independent_joint_measurement` 是额外角度传感的候选链路，但其
  `dq/ddq` 仍必须从测量角度滤波和微分，不能读取仿真真值导数。

## 9. 独立角度测量不能解决什么

相机或 IMU 不能自动修复束缚带等效作用点距离、力的坐标系/符号、
Jacobian 中的错误 `L1/L2`、错误 `q0`、TCP 力噪声或传感器时延。角度传感
本身还会有安装偏差、遮挡、漂移和噪声。因此独立角度较准时，仍需用
`assumed_geometry` 计算 `J_assumed.T @ F`，作用点和中性角仍要另行标定。

## 10. 为什么真实实验需要重复几何标定

受试者摆位、骨性标志定位、束缚带松紧和安装位置会在每次穿戴后变化。
一次标定的髋中心、`L1` 和尤其“膝到等效牵引点”的 `L2` 不能默认在后续
实验中保持准确。真实实验应在每次安装后重复记录人体测量、髋中心、TCP
作用点和角度参考，并同时保存 TCP 与侧视/IMU 运动学供一致性检查；仅保存
数组行号或机器人 TCP 位置不足以证明人体关节状态正确。

## 11. 为什么动态束缚带滑移应单独研究

本阶段的 `L2` 偏差是一次安装后保持不变的静态标定误差。随时间变化的作用
点、带体伸长或皮肤相对滑移会使运动学和力传递映射共同随时间改变，与静态
几何误差是不同问题。如果在同一阶段同时加入，就难以区分“初始标定错误”
和“运动中接口变化”。因此当前不实现时间变化 `L2`，动态滑移必须作为后续
独立变量研究。

## 12. 当前仍然只是虚拟观测链验证

本阶段验证的链路是：

```text
true joint motion
    -> virtual pull-point measurement
    -> geometry/sensor error
    -> reconstructed q/dq/ddq
    -> J_assumed.T @ F
    -> five-parameter identification
    -> unseen-trajectory evaluation
```

适用域运行时判断只允许使用重建的 `q_est/dq_est/ddq_est`；真实状态只在
事后计算 `domain_false_accept_rate` 和 `domain_false_reject_rate`。
`outside_domain` 结果只用于暴露外推风险，不支持模型有效的主结论。

当前没有真实患者、相机、IMU、束缚带滑移或 ROKAE 数据，也没有验证
真实设备时钟、wrench 坐标系、实时线程或安全门控。阶段 4.5D 不接入
真实机器人控制环，不导入真实 SDK，不修改 `hardware/`、`collection/`、
`control/` 或安全配置，也没有加入轨迹优化、PINN、MPC 或触觉。

阶段 4.5D 最终只能表述为：在当前二维虚拟下肢模型中，静态几何标定误差
和运动学观测误差对五参数辨识与未见轨迹预测的离线软件敏感性验证。
