# 动态力值审计

本审计的历史数值基于迁移前 `0~120°` 髋角图谱、`5~130°` 膝角图谱和
`software_test_trajectory`。结果只用于软件验证，不是患者力预测、临床
参考、机器人命令或安全阈值。

## 审计范围

需要分开看两类数据：

1. **完整准静态工作空间**：每名虚拟受试者10,866个床面以上姿态，包含
   关节范围边界和接近膝伸直的高条件数区域。
2. **连续测试轨迹区域**：只经过 `(20°,20°) → (120°,120°) → 返回`
   的一维关节路径，不覆盖完整工作空间边界。

完整工作空间有效点的力幅统计：

| subject | 中位力 N | 最大有效力 N |
|---|---:|---:|
| baseline | 115.85 | 556.09 |
| hip_stiff | 153.18 | 998.08 |
| knee_stiff | 204.78 | 453.66 |
| heavy_leg | 123.39 | 681.00 |

`hip_stiff` 还有14个姿态超过当前 `1000 N` 软件异常值上限。这些点保持
`force_mapping_valid=False`、力字段为 NaN、原因为
`force_magnitude_limit_exceeded`。没有降低阈值，也没有用裁剪数据掩盖
问题。

## 完整工作空间最大有效力

当前最大有效值来自 `hip_stiff`：

| 字段 | 数值 |
|---|---:|
| q_hip | 78° |
| q_knee | 5° |
| x_pull | 0.1750 m |
| z_pull | 0.6977 m |
| Jacobian condition number | 55.30 |
| Fx robot on leg | -300.99 N |
| Fz robot on leg | -951.61 N |
| force magnitude | 998.08 N |

关节力矩分项：

| 分项 | τ_hip N·m | τ_knee N·m | 映射后力幅 N |
|---|---:|---:|---:|
| gravity | 7.83 | -1.84 | 94.08 |
| stiffness | 35.60 | -1.05 | 904.16 |
| total | 43.44 | -2.88 | 998.08 |

该大力同时来自参数和几何：

- `hip_stiff` 的髋刚度提高到 `30 N·m/rad`，在78°髋屈曲时产生较大被动
  刚度力矩；
- 膝角只有5°，Jacobian condition number 为55.30，关节力矩到末端力的
  映射发生明显几何放大；
- 因此这里的主导项是**髋被动刚度 + 接近伸膝的映射放大**，不是惯性或
  阻尼。

峰值处力矩及其独立映射贡献：

| 分项 | τ_hip N·m | τ_knee N·m | 映射后力幅 N |
|---|---:|---:|---:|
| inertia | 1.362 | -0.259 | 4.79 |

| damping | 0.588 | 0.441 | 9.92 |
| stiffness | 3.358 | 6.716 | 117.17 |
| total | 38.160 | 0.628 | 243.04 |

因此当前测试轨迹峰值主要由**重力与膝刚度**共同造成；惯性和阻尼随速度
增加，但在这些虚拟参数和3秒单程时间下仍是次要项。condition number
11.96 也说明该峰值不是奇异附近的极端几何放大。

当前直线关节路径满足 `q_knee=q_hip`、`dq_knee=dq_hip`，因此小腿绝对
方向 `q_hip-q_knee` 始终为0°，小腿在整个测试动作中保持水平。当前路径
的髋、膝科氏/离心项大小相等、方向相反且都很小；这只是该测试路径的性质，
不能推广为一般轨迹没有科氏力矩。

## 速度效应结论

以 baseline 为例，slow→nominal→fast：

- 惯性力矩范数峰值：`0.0920 → 0.3681 → 1.4724 N·m`；
- 阻尼力矩范数峰值：`0.6818 → 1.3635 → 2.7271 N·m`；
- 峰值末端力：`183.81 → 184.55 → 189.13 N`。

惯性按时间缩放明显增加、阻尼随速度增加，但末端总力变化较小，因为当前
轨迹仍由重力和线性刚度主导。这一结论只针对当前软件测试路径和虚拟参数。

## 安全解释边界

- `1000 N` 只是异常数值审计上限，绝不是未来机器人安全阈值。
- 完整图谱的近千牛结果不能解释为真实患者会承受该力。
- 测试轨迹没有经过完整图谱中 `q_knee=5°` 的高放大区域。
- 真实系统还缺少患者主动肌肉力、非线性末端阻力、痉挛、摩擦、束缚带
  弹性/滑移、分布式接触、机器人本体动力学和真实 wrench 语义。
- 在参数辨识、真实受试者验证和独立安全分析之前，本结果不得进入真实
  ROKAE 控制或安全配置。
