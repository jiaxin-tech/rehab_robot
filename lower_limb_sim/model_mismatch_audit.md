# 阶段 4.5C：动力学模型失配审计

本审计只讨论复杂虚拟受试者生成模型与现有五参数灰箱辨识模型之间的
结构差异。结果不是患者测量、临床结论、机器人控制器或安全阈值。

人体角度定义保持不变：

```text
theta_shank = q_hip - q_knee
```

髋屈曲总工作空间上限仍为 120°。本阶段没有引入 `q_hip + q_knee`
机械臂动力学。

## 1. 为什么 clean 近零误差不代表真实人体

阶段 4 clean 数据由同一套线性质量、刚度和阻尼方程生成与辨识，因此近零
残差首先证明了公式、符号、力映射和优化流程自洽。真实人体可能存在角度
相关刚度、速度相关阻尼、跨关节耦合、主动肌力和束缚带效应，所以 clean
结果不能直接外推为真实患者辨识精度。

## 2. 生成模型与辨识模型失配

阶段 4.5C 的虚拟生成器可以包含三次刚度、由势能导出的髋膝耦合、二次
速度阻尼和小幅平滑残余力矩；辨识器仍固定为：

```text
theta = [mass_scale, K_hip, K_knee, B_hip, B_knee]
```

复杂项只用于生成 `Fx/Fz` 和事后审计。估计器输入被投影为
`q/dq/ddq/Fx/Fz`，观测力矩仍由 `J.T @ F` 重建；生成器总力矩、复杂分项、
场景名和生成参数不进入拟合。

## 3. 等效参数不等于真实生理参数

当真实关系非线性时，一个常数 K 或 B 是训练运动区域内的最佳线性近似。
它可能吸收一部分三次刚度、耦合或速度平方阻尼，因此不应把估计值与生成
模型中的线性系数差异自动判为失败，也不能把它解释成直接测得的组织刚度
或阻尼。主要判断依据是未见轨迹上的力矩和端点力预测。

## 4. 为什么未见轨迹更重要

训练残差可以通过等效参数局部补偿。只有在没有参与拟合的新路径、新相位、
新幅值和新速度上仍保持较小误差，才能说明简化模型在参考轨迹邻域具有
预测价值。`interpolation_test`、`boundary_test` 和
`outside_domain_test` 均不会进入参数拟合。

## 5. 训练域外预测边界

`outside_domain_test` 明确包含超出辨识状态覆盖的样本，但仍限制在软件人体
总工作空间内。它只用于暴露外推风险，不纳入“模型有效”的主结论。域外
误差即使很大，也不能通过删除轨迹或高误差样本来掩盖。

## 6. 角度相关残差

三次刚度在中等角度贡献较小，在大屈曲角的贡献快速增加。简单线性模型
通常会在大角度区域出现系统性低估或弯曲残差。残差与角度的相关性和散点
趋势只能标记 `possible_nonlinear_stiffness_mismatch`，不能自动确定真实
生理机制。

## 7. 相位变化与关节耦合

耦合势能取决于髋膝相对组合。训练路径若让两关节按近似固定比例运动，独立
K 可能部分吸收耦合效应；`phase_shift_small` 改变两关节相位关系，更容易
暴露髋残差与膝角、膝残差与髋角的交叉相关。诊断标记
`possible_joint_coupling_mismatch` 仍只是软件线索。

## 8. 何时简单模型仍有价值

如果 identified equivalent model 在训练覆盖内部的新路径上明显优于固定
generic baseline，且 NRMSE、峰值误差和残差结构满足软件工程门槛，五参数
模型仍可作为参考轨迹邻域的紧凑预测器。该结论只对已验证运动区域、速度和
虚拟生成条件成立。

## 9. 何时需要扩展模型

若 mild 失配已在插值轨迹持续超过门槛，或残差随角度、速度和跨关节状态
呈稳定结构，说明五参数模型无法覆盖目标区域。此时才有理由研究更丰富的
物理项或残差模型；本阶段不加入 PINN、神经网络、MPC、轨迹优化或触觉。

## 10. NRMSE 和小范围保护

统一公式为：

```text
NRMSE = RMSE / (max(true torque) - min(true torque) + epsilon) * 100%
```

单位为百分比。真实力矩范围小于配置门限时标记
`nrmse_unreliable_small_range`，不能把小分母产生的巨大百分比当作可靠
结论。

## 11. 数据和硬件边界

- train 是唯一拟合输入；validation 和全部未见轨迹只用于评价；
- generic baseline 与 identified model 使用同一组观测样本比较；
- 复杂生成项可以保存在输出 CSV 供事后审计，但会在估计调用前移除；
- 时间同步主实验为无延迟可靠对齐，不把 4.5B 的变化延迟混成主变量；
- 没有读取或导入真实 xCoreSDK，没有调用机器人；
- 没有修改 `hardware/`、`collection/`、`control/` 或安全配置。

阶段 4.5C 最终只能表述为：复杂虚拟受试者对简化五参数模型的未见轨迹
预测验证，不能表述为真实患者参数估计、临床有效性或真实机器人安全验证。
