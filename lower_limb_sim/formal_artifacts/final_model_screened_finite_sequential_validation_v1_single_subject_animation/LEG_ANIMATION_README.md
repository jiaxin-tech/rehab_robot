# Simulated leg motion through all finite-validation rounds

`SINGLE_SIMULATED_LEG_ROUNDS.gif` animates the frozen offline case `baseline__combined_mild` in this
order: Reference → C1 → C2 → C3 → final measured/virtual-truth selection.

The left panel shows the hip, knee, and distal strap-equivalent traction point
moving through each complete 24 s cycle.  A faint dashed leg is the Reference
pose at the same time during candidate rounds.  The colored trail is the distal
traction-point path.  The right panels show hip and knee angles with a moving
time cursor.

- Frames: 165
- Resolution: 1280×720
- Compressed duration: 18.30 s
- Round J values: [1.0, 0.965492695909, 0.970223767367, 0.976270020461]

L2 is the project-defined strap-equivalent traction-point distance, not an
anatomical ankle.  This is frozen offline simulation evidence and contains no
robot motion or human observation.
